# 01 地基：MDP / 动态规划 / MC / TD（表格时代）

> **一句话定位**：RL 的“地基”——别家学“看图认物”，这里学“怎么描述世界、怎么算账”。DP 是全知上帝，MC 等账单，TD 每天估账，SARSA 胆小，Q-Learning 理想。
> 状态：✅ 2 站全部完成 | 环境：手写 GridWorld + CliffWalking，纯 numpy 零依赖 | 实跑：01 秒级 + 02 约 95s（5 种子）

## 通俗理解：先有账本，再谈学习

| 阶段 | 通俗说 | 类比 | 落点 |
|---|---|---|---|
| MDP/贝尔曼 | 世界说明书 + 账本自洽 | 记账规则：现在值多少=眼前+打折未来 | `01`：V(5)=−2，两步到终止 |
| 动态规划 | 全知上帝直接对账 | 对着答案抄：转移全知道 | `01`：PI 3 轮 vs VI 4 轮同解 |
| MC | 等账单来了再平摊 | 月底看总账 | `02`：b=300 MSE 9202，方差大 |
| TD | 每天看隔壁估房价 | 自举：用估计更新估计 | `02`：b=30 方差 18 vs MC 2172 |
| SARSA/Q-Learning | 胆小鬼 vs 理想主义者 | 按实际走的学 vs 按最好情况学 | `02`：贪心 −17 安全 vs −13 最优 |

## 学习目标

1. 写出 MDP 五元组与贝尔曼方程，默写值迭代更新
2. 复现策略迭代/值迭代，理解 max 收缩最快
3. 理解 MC 无偏高方差 vs TD 有偏低方差
4. 理解 on-policy/off-policy 在悬崖上的行为差异
