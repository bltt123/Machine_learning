# 03 CNN 下游任务：分割与检测

> **一句话定位**：02 家族学会“看图认物”（分类），03 家族学会“落地干活”——不仅知道*是什么*，还要知道*在哪、有多大、轮廓长啥样*。是 CV 从实验室到产品的分水岭。
> 状态：✅ 3 站全部完成 | 数据：`Oxford-IIIT Pet` 7393 张猫狗写真复用全家 | 公共模块：`common/` | 环境：`LLM_learning`（torch 2.5.1+cpu）

## 通俗理解：分类 → 分割 → 检测，层层递进

| 任务 | 通俗说 | 类比 | 指标 | 家族内落点 |
| :--- | :--- | :--- | :--- | :--- |
| **分类**（02 家族） | 看一张图，答“这是什么” | 点名：这是猫 | accuracy | 前置 |
| **分割**（01 站） | 给**每个像素**涂色 | **涂色本**：猫的每个像素涂“前景”，其余涂“背景” | **mIoU / Dice**：涂得准不准，边界错一圈就掉分 | 自训 U-Net vs FCN，`+1.36pt mIoU` 证明跳跃连接专治边界糊 |
| **检测**（02/03 站） | 给**每个物体**画框+贴标签 | **点名+画圈**：这有1只猫在左上，那有1把椅子在右边 | **mAP**：圈得准 + 点得全；**NMS** 去重重叠框 | 预训练推理对比 + 手写 NMS + YOLO 网格思想 |

> **下游**的含义：02 的 `ResNet/U-Net 编码器`是通用“眼睛”，03 就是给这双眼睛接上不同的“手”去涂色/画框。07 生成模型的 Diffusion 也复用 U-Net 这双眼睛。

### 为什么全是猫？为什么复用数据？

`Oxford-IIIT Pet` 本质是**猫狗写真集**（37 品种，阿比西尼亚猫 `Abyssinian_100` 等）。它自带两套标签：`图片.jpg` + `trimap.png掩码`（告诉你哪个像素是猫）。

*   **01 分割**：用 `图片+掩码` 一起**自训**，学涂色。
*   **02 检测**：只用 `图片`，拉来 **COCO 预训练的检测器**（在 80 类上已见过几十万只猫）直接**推理**——`cat 0.98` 不是我们教的，是老司机本来就会。旁边误检的 `chair 0.73` 是背景纹理被硬按 80 类套错，正好用来分析误差。**工业界就这么用：大模型预训练 + 小数据微调，本家族为 CPU 友好只做前半段。**

所以你看到的不是“我们教模型认猫”，而是“拉一个现成老司机来考他认不认得这批猫”。

## 学习目标

1. 理解语义分割（FCN → U-Net）与目标检测（two-stage vs one-stage）两大技术路线
2. 掌握分割/检测的专用指标：mIoU、Dice、mAP、NMS、Anchor，以及 Focal Loss 对不均衡的缓解
3. 学会用 torchvision 预训练模型做推理与可视化（生产实际做法）

## 算法清单（学习检查表）

### 分割
- [x] FCN（全卷积、上采样）→ `01`（173.4万参，mIoU 0.5273，基线）
- [x] U-Net（编码器-解码器 + 跳跃连接）★重点 → `01`（192.7万参，**mIoU 0.5409 / Dice 0.6324**，同容量 **+0.0136 / +0.0315**，边界 IoU 0.259 是瓶颈）

### 检测
- [x] Faster R-CNN（two-stage：RPN + RoI，两步走精度高）→ `02`（41.8M，同阈值检出 6/4 图，cat 0.96~0.98）
- [x] RetinaNet（one-stage：Focal Loss 压制背景 1:1000）→ `02`（34.0M，更轻，5/4 图，103 图同猫双框残留）
- [x] YOLO 系列（one-stage 网格回归，一眼看全）→ `03`（S=7 B=2→98框 vs 2000候选，NMS 0.3→3框/0.9→8框，分数阈 0.93 时 R 0.667）
- [x] Mask R-CNN（实例分割 = 检测 + 分割头）→ `02`（44.4M，框+掩码，9/4 图，掩码不抑制分类误检）

> 共同件：**Anchor**（预设多尺度参考框，学偏移而非绝对坐标）、**IoU**（框交并比）、**NMS**（手写与 `torchvision.ops.nms` 完全一致 `[0,3,5]`）

## 场景速查（选型指南，数字来自本家族实测；场景列是人话例子，先看场景再挑推荐）

| 场景（能干什么活） | 推荐 | 支撑数据 | 要点 |
|---|---|---|---|
| 在 CT/MRI 上描肿瘤、血管，标注只有几百张、边界必须精 | **U-Net** | mIoU 0.5409 vs 0.5273，Dice +0.0315 | 跳跃连接专治边界糊 |
| 遥感涂道路、涂建筑：边界要求不高、要跑得快省算力 | FCN | 少 11% 参数、少 20% 计算 | 但边界糊、易过拟合 |
| 目标又薄又小（边界带/小器官），纯 CE 学不动 | CE + Dice 联合 | 边界占比 11.8% 时 Dice 仍能拉动 | 纯 CE 会忽视小类 |
| 电路板找虚焊、CT 框肺结节：漏一个就是事故，慢点没事 | **Faster R-CNN** | 6 vs 5 检出，cat 分数 0.96~0.98 更高 | two-stage 精修 |
| 车间便宜摄像头、视频流边看边框：又要准又要省芯片 | **RetinaNet** | 34.0M 最轻，Focal 抗背景不均衡 | one-stage 一步到位 |
| 机械臂抓杯子要知道杯把在哪、自动驾驶判行人动向 | **Mask R-CNN** | 框+掩码同出，9 检出含形 | 实例分割 = 检测+分割 |
| 手机扫码、抖音贴纸、监控数人：一帧 30ms 内框完 | **YOLO** | 98 框 vs 2000 候选，F1 1.0@0.90 | 一眼看全，无 RPN；小/密目标需多尺度 |
| 同一只猫被框了两三下，要留一张 | NMS | IoU 0.3→3框 / 0.9→8框，手写与官方一致 `[0,3,5]` | 越小越严，密集取 0.3 |
