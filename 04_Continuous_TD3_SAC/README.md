# 04 连续控制家族：DDPG / TD3 / SAC

> **一句话定位**：动作从“选一个”变成“拧一个旋钮”——DDPG 莽（确定性+探索噪声），TD3 三件防具（双Q/延迟/平滑）治高估，SAC 留后路（随机策略+熵）。
> 状态：✅ 2 站全部完成 | 环境：`Pendulum-v1`，torch 2.5.1+cpu | 实跑：01（5 变体×2 种子×20k 步）+ 02（SAC auto/fixed + TD3×2 种子×20k 步），7 张图

## 通俗理解：从离散到连续

| 阶段 | 通俗说 | 类比 | 落点 |
|---|---|---|---|
| DDPG | 确定性输出 + 探索噪声 | 莽：一个主选手直接猜动作 | `01`：−294.5±195.8，高估 176 |
| TD3 | 双Q取小 + 延迟更新 + 目标平滑 | 三件防具 | `01`：−191.3±66.5，高估仅 17 |
| SAC | 输出分布 + 熵正则 + 自动温度 | 留后路，别死心眼 | `02`：auto −246.6 / fixed −113.3 |

## 学习目标

1. 写出确定性策略梯度（DDPG/TD3）与重参数化随机策略梯度（SAC）
2. 解释 TD3 三招各治什么，并知道它们**不是**普适的
3. 解释 SAC 温度 α 的作用与 target entropy
4. 理解奖励尺度对熵正则有效性的影响

## 核心结论（如实）

- **TD3 > DDPG**：20k 步 TD3 反超且方差小 3 倍；双 Q 把高估压了 10 倍。但 12k 步时 TD3 还输——延迟更新要时间兑现
- **三招非普适**：Pendulum 上只有**延迟更新**明确有益（no_delay 最差 −428）；双 Q 和目标平滑在低维稠密奖励任务不划算，别 cargo-cult
- **SAC 熵正则失效坑**：Pendulum 奖励幅度大，`α·logπ` 被 Q 碾压，熵照样崩，auto 温度也救不回。要先用奖励归一化
- **2 种子限制**：连续控制 CPU 成本高，std 仅作趋势参考
