# 06 LLM 对齐家族：DPO / GRPO（toy）

> **一句话定位**：把 05 的“离线偏好数据”搬到语言模型——DPO 拿偏好对直接优化（无奖励模型），GRPO 用组内均值当基线（无 critic）。用 toy 任务把链路走通，不碰真 LLM。
> 状态：✅ 2 站全部完成 | 环境：toy 对齐任务（MLP 当语言模型，纯 torch CPU） | 实跑：01（DPO 家族×2 种子 + β 消融）+ 02（GRPO/REINFORCE + 消融），6 张图

## 通俗理解：对齐的两种省钱法

| 阶段 | 通俗说 | 类比 | 落点 |
|---|---|---|---|
| DPO | 只给偏好对，自己悟隐式奖励 | 只告诉你 A 比 B 好 | `01`：0.906，β 是 accuracy-KL 旋钮 |
| IPO | 平方损失更保守 | 步子别迈太大 | `01`：KL 最小 1.464 |
| cDPO | 标签平滑抗噪 | 别太信一条偏好 | `01`：0.906 |
| ORPO | SFT + 偏好合一 | 一次干两件事 | `01`：0.906 |
| GRPO | 同题多解，组内均值当基线 | 比自己组平均好就鼓励 | `02`：0.906，省掉 critic |

## 学习目标

1. 写出 DPO 隐式奖励与损失，理解 β 的作用
2. 区分 IPO / cDPO / ORPO 相对 DPO 改了什么
3. 写出 GRPO 组内优势，理解它如何省掉 critic
4. 理解 KL 惩罚何时咬合（奖励与参考冲突时）
5. 走通 VERL 式 GRPO 链路（rollout→reward→组内优势→KL 约束的策略梯度）

## 核心结论（如实）

- **DPO 家族在干净偏好上同分（~0.9）**，差异集中在 KL/稳健性：**IPO 最保守（KL 1.464）**
- **β 是清晰的 accuracy-KL 旋钮**：噪声偏好下 β 小→激进（KL 大、准确率高），β 大→保守
- **GRPO 省掉 critic**：组内均值即基线，代价是“同题多次采样”
- **组大小 G 是超参**：G=2 明显吃亏（0.828），G=4~8 最好
- **KL 惩罚只在奖励与参考冲突时咬合**：toy 任务上 β 消融平坦
- **最贵的坑**：toy 任务训练/评估必须共享同一个 W，否则连 SFT 都崩（0.094）
