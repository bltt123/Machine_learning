## 核心结论（如实）

- **手写 DQN 与 SB3 一致（167.8≈177.9）**→ 02 家族的手写实现正确，交叉验证通过
- **手写 PPO 落后 SB3（308 vs 500）**：差距在调参（网络大小/初始化/advantage），不在实现正确性
- **DQN 对更新频率敏感**：SB3 默认 train_freq=4 只 130，改每步更新到 177.9
- **工具链按规模选**：单机→SB3/Tianshou，分布式→RLlib，GPU 仿真→Isaac，LLM→VERL，真机→SERL
- **硬件门槛**：本地无 NVIDIA GPU，Isaac Gym 只能阅读
