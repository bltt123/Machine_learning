# KNN / SVM — 手写数字识别

## 项目简介
使用手写数字图片练习 **KNN** 和 **SVM** 两种经典分类算法，并比较它们在图像分类任务中的表现。

## 算法介绍
### 1. KNN（K-Nearest Neighbors）：近朱者赤的“随大流”算法
🎯 通俗解释
想象你搬到一个新小区，想知道自己算“中产”还是“富豪”。KNN 的做法很简单：看看离你最近的 K 个邻居都是什么人。如果 K=5，其中有 4 个是富豪，那 KNN 就判定你也是富豪。它的核心逻辑就是“物以类聚，人以群分”，看你身边最近的 K 个邻居是谁，就判断你是谁。
⚙️ 核心原理
距离度量：靠计算特征空间中的距离（最常用的是欧氏距离，即直线距离）来衡量“相似度”。
预测规则：选出距离最近的 K 个样本，分类任务采用“少数服从多数”投票，回归任务则取这 K 个邻居的平均值。
⚠️ 致命弱点：
对特征尺度极度敏感：如果特征A的范围是 0-1，特征B的范围是 0-10000，距离计算会被特征B完全主导。因此，KNN 在训练前必须做数据标准化（如 Min-Max 或 Z-score）。
维度灾难：在高维空间中，所有点之间的距离都会变得差不多，导致算法失效。
惰性学习，预测开销大：每次预测都要算一遍所有样本的距离，数据量大时速度很慢。
💼 应用场景
推荐系统初步：找和你历史行为最相似的用户，推荐他们喜欢的内容。
欺诈检测：识别与已知欺诈案例特征高度相似的异常交易。
医疗诊断：根据症状的相似度判断疾病类型。
简易相似度推荐演示、小样本医疗辅助分类；工业大数据场景很少直接上线原生 KNN（预测时需逐个计算与所有训练样本的距离，计算量 O(N·D) 过高，N=样本数，D=特征数）。

### 2. SVM（Support Vector Machine）：寻找“最宽马路”的几何大师
🎯 通俗解释
假设你要在红蓝两色的球中间放一块木板把它们分开。SVM 不是随便找个缝隙塞木板，它的目标是寻找一条“最宽的马路（最大间隔）”，让马路的两边紧紧贴着离得最近的红球和蓝球（这些球就叫“支持向量”）。只要马路够宽，哪怕以后再来几个新球，也不容易掉进对方的阵营。即间隔越宽，模型泛化能力越强。
⚙️ 核心原理
最大间隔超平面：核心目标是最大化分类边界（超平面）到最近样本点（支持向量）的几何距离（Margin）。
核技巧（Kernel Trick）：如果数据在低维空间根本分不开（比如红球把蓝球包围了），SVM 会通过核函数（如 RBF 高斯核）把数据“折叠”或映射到高维空间，让它在新空间里变得线性可分。
软间隔（Soft Margin）：现实数据总有噪声。SVM 允许少数样本越界（通过惩罚参数 C 控制），在“马路最宽”和“分类错误最少”之间找平衡，避免过拟合。RBF 核还通过 gamma 参数控制单个样本的影响范围。
💼 应用场景
图像识别：人脸检测、手写数字识别（SVM 配合 RBF 核在小样本高维图像上表现极佳）。
文本分类：垃圾邮件过滤、新闻分类（文本数据通常是高维稀疏的，SVM 非常擅长）。
生物信息学：基因表达数据分析、蛋白质结构预测。等生物小样本数据分析。

## 说明
- MNIST 规模较大，KNN 预测较慢，因此使用 PCA 或子集进行实验
- SVM 适合中等规模特征空间，配合标准化与 PCA 通常效果较好





# 项目总结：MNIST 手写数字识别 — KNN vs SVM 实战

## 1. 项目背景与业务目标
- **任务**：根据 28×28 灰度手写数字图片（784 个像素特征），预测其是 0~9 中的哪个数字（10 分类）
- **核心目标**：在**同一份数据**上横向对比 **KNN（K 近邻）** 与 **SVM（支持向量机）** 两种经典分类算法，理解它们的原理差异与适用场景

## 2. 数据概况
| 数据集 | 规模 | 说明 |
|---|---|---|
| train.csv | 42,000 × 785 | 训练集，第 1 列为标签（0~9），其余 784 列为像素值（0~255） |
| test.csv | 28,000 × 784 | 测试集，无标签 |
| sample_submission.csv | 28,000 × 2 | 官方提交样例（ImageId, Label） |

- 10 个数字类别，类别分布基本均衡
- 像素值范围：0~255（灰度图）

## 3. EDA 结论
- 类别分布基本均衡，每个数字约 4,000~4,200 个样本
- 样本可视化：手写数字清晰可辨，部分数字有书写变形
- **核心观察**：784 维特征空间高维，KNN 直接计算距离会很慢，SVM 也需要降维加速

## 4. 数据预处理
- **标准化**：使用 StandardScaler（Z-score，均值 0 方差 1）对像素特征做标准化（KNN/SVM 都对尺度敏感）
- **PCA 降维**：保留 95% 方差，从 784 维降至 **284 维**，大幅加速模型训练与预测
- **子集采样**：为平衡速度与效果，使用 8,000 训练样本 + 2,000 验证样本进行模型对比

## 5. 模型构建
### KNN（K-Nearest Neighbors）
- **原理**：基于欧几里得距离，取 K 个最近邻进行多数投票
- **参数对比**：K=1,3,5,7,9
- **结果**：K=7 时验证集准确率最高（0.9110）

### SVM（Support Vector Machine）
- **原理**：寻找最大间隔超平面，配合核技巧处理非线性问题
- **核函数对比**：linear（线性核）、rbf（高斯径向基核）、poly（多项式核）
- **结果**：
  - SVM-linear：0.9030
  - **SVM-rbf：0.9385（最佳）**
  - SVM-poly：0.9025

## 6. 模型评估与结果
| 模型 | 验证集准确率 |
|------|-------------|
| KNN(K=1) | 0.9040 |
| KNN(K=3) | 0.9080 |
| KNN(K=5) | 0.9075 |
| **KNN(K=7)** | **0.9110** |
| KNN(K=9) | 0.9070 |
| SVM-poly | 0.9025 |
| SVM-linear | 0.9030 |
| **SVM-rbf** | **0.9385** |

**结论**：
- KNN 简单直观，K 值过大/过小都会影响效果
- **SVM 配合 RBF 核在 MNIST 上通常优于 KNN**
- 两者都依赖标准化，PCA 能大幅加速 KNN

## 7. 混淆矩阵分析
- 最佳模型（SVM-rbf）在验证集上的 macro avg F1-score 为 0.94
- 主要错误集中在形近数字之间（如 6 与 2、7 与 9、8 与 3/5），符合人类识别的直觉

## 8. 预测与提交
- 用最佳模型（SVM-rbf）对测试集 28,000 张图片进行预测
- 生成 `submission.csv`，行数与官方样例一致

## 9. 项目收获
- 掌握 KNN 的距离度量、K 值选择对模型的影响
- 理解 SVM 的最大间隔原理、核技巧的作用
- 学会高维数据的降维方法（PCA）
- 实践多模型对比的完整流程

## 10. 可优化方向
- 尝试更多 K 值（如 11、13）或使用 KD-Tree 加速 KNN

- 尝试其他降维方法（t-SNE、LDA）
- 使用深度学习模型（CNN）作为对比基准
