1. 线性回归（Linear Regression）：预测“具体数值”
🎯 通俗解释
线性回归的核心思想就是“拟合一根线”。它试图找到一条最完美的直线（或高维空间里的超平面），让这根线尽可能贴近所有的数据点，从而根据已知条件去预测一个连续的具体数值。
⚙️ 核心原理
模型假设目标变量和输入特征之间存在线性关系（公式类似 $y = wx + b$）。为了让这条线最贴合数据，我们需要最小化真实值和预测值之间的误差平方和，也就是 MSE（均方误差） 损失。
⚠️ 面试避坑指南：找最优参数有两种方式，千万别混淆！
最小二乘法：这是解析解。通过数学公式直接一步算出最优的 w 和 b ，不需要迭代。缺点是数据量极大时计算成本高。
梯度下降法：这是迭代优化算法。就像下山一样，不断调整参数 w 和 b ，一步步逼近误差最小的山谷底部。大数据和高维特征场景下更常用。
💼 应用场景
金融：预测贷款额度、评估保险费率。
商业预测：根据房屋面积预测房价，根据广告投入预测销售额或营收（注意：不适合预测股票走势，因为现实股价是非线性且强噪声的）。
工业制造：分析生产参数，预测设备的剩余使用寿命（RUL）等连续数值。

业务问题：给定房屋的 79 个特征（面积、地段、装修、车库、地下室、建造年份等），预测其销售价格 SalePrice
问题类型：监督学习中的回归问题（预测连续值）
实际意义：对应房地产行业中的估价/定价场景，掌握特征如何影响房价的量化方法
2. 数据理解
项目	内容
训练集  1,460 行 × 81 列（80 项特征 + SalePrice 标签）
测试集  1,459 行 × 80 列（无标签，待预测）
特征构成  数值特征 35+、类别特征 40+（41 个类别列）
数据质量  存在较多缺失值（19 列有缺失）

关键发现（EDA）：
SalePrice 严重右偏（偏度 1.88，远大于 0）
与房价强相关的特征：OverallQual（整体质量）、GrLivArea（居住面积）、GarageCars/Area、TotalBsmtSF 等
高相关特征（如 TotalBsmtSF 与 1stFlrSF）暗示存在多重共线性
3. 数据清洗
类别特征缺失 → 填 "None"（PoolQC、Alley、Fence、FireplaceQu 等，缺失本身代表"没有该设施"，是有意义的）
数值特征缺失 → 填 0（GarageYrBlt、TotalBsmtSF、卫浴数量等，"无车库/无地下室"用 0 表达）
异常值处理：删除 GrLivArea > 4000 且 SalePrice < 300000 的极端样本（面积巨大但价格反常低，属于录入异常，共删 2-4 行）
4. 特征工程
衍生特征（领域知识驱动）：
TotalSF = 地下室 + 一层 + 二层面积（房屋总面积）
HouseAge / RemodAge（房龄、翻新后年数）
TotalBath（折算总卫浴数）
TotalPorchSF（户外空间总面积）
skew 处理：对 17 个右偏数值特征做 log1p 变换，目标变量 SalePrice 同样取 log1p（偏度从 1.88 降到约 0.07，接近正态）
多重共线性控制：VIF 迭代消除（阈值 10），并保护核心解释特征（OverallQual / YearBuilt / GrLivArea / LotArea）
类别编码：One-Hot 编码（handle_unknown="ignore"）
5. 建模与验证策略
采用 Pipeline（缺失填充 → 独热编码/标准化 → 模型） 封装，保证训练/测试处理一致、避免数据泄漏。同时对比 3 个模型：

模型	5 折 CV-RMSE (log 空间)
LinearRegression  略高（对共线性敏感）
Ridge   介于两者之间
Lasso   0.1127（最低，胜出）
Lasso 通过 L1 正则化自动做特征选择，恰好缓解了较高的特征维度问题。

6. 模型评估

系数解读：OverallQual、GrLivArea 等标准化系数最大，验证了 EDA 阶段的判断
