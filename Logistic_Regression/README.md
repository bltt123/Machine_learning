2. 逻辑回归（Logistic Regression）：预测“类别发生概率”
🎯 通俗解释
虽然名字里带“回归”，但它其实是用来做分类的（特别是二分类）。它不会直接告诉你“是”或“否”，而是告诉你“这件事发生的概率有多大”。比如，它不会直接说客户会违约，而是说“该客户有 85% 的概率会违约”。
⚙️ 核心原理
它的基础其实也是线性回归。先通过线性公式给数据打个分（加权求和），但因为这个分数可能是无穷大或无穷小，所以它引入了一个神奇的 Sigmoid 函数（S形函数）。这个函数能把任意分数“压缩”到 0 到 1 之间，变成一个概率值。
⚠️ 核心考点与业务常识：
损失函数不是 MSE：逻辑回归训练时绝对不能用均方误差（MSE），而是使用 交叉熵损失（Cross-Entropy）。如果用 MSE 搭配 Sigmoid，会导致损失函数变成非凸函数，极易陷入局部最优或梯度消失，很难收敛。
0.5 只是默认阈值：“概率大于 0.5 归为是”只是默认设定。在实际业务中，阈值是根据需求手动调整的。例如在金融风控中，为了“宁可错杀，不要放过”，我们可以把阈值调到 0.3，只要概率 > 0.3 就判定为高风险。
多分类扩展：逻辑回归不仅限于二分类，通过 One-vs-Rest 或 Softmax 回归，它同样可以处理多分类任务。
💼 应用场景
营销与广告：预测用户看到广告后点击的概率（CTR预估），预测客户流失或购买的可能性。
医疗诊断：根据患者的生理指标（如血压、年龄等），预测其患某种疾病的风险。
金融反欺诈：判断一笔交易是正常交易还是欺诈交易。
