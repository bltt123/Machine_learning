# 朴素贝叶斯 — 垃圾短信分类

## 项目简介
使用 **朴素贝叶斯（Naive Bayes）** 算法对短信进行垃圾（spam）与非垃圾（ham）二分类。

## 算法介绍
### 朴素贝叶斯（Naive Bayes）：概率推理的“证据收集器”
🎯 通俗解释
想象你是个侦探，要判断一封邮件是不是“垃圾邮件”。你会收集证据：有“免费”这个词吗？有“中奖”吗？有“点击链接”吗？
朴素贝叶斯就是把你看到的每个词当成一条独立的证据，分别计算它们出现在垃圾邮件里的概率，然后把这些概率乘起来得到最终后验概率。如果综合概率极高，就判定为垃圾邮件。
⚙️ 核心原理
贝叶斯定理：根据观察到的特征（证据），反推样本属于某个类别的后验概率。
⚠️ “朴素”的由来：它做了一个极其“天真”的假设——特征条件独立。即假设“免费”和“中奖”这两个词的出现是完全互不相关的。虽然现实中这不可能，但这种简化让计算变得极其高效，模型依然效果优秀。
⚠️ 零概率问题：如果某个词在训练集的垃圾邮件中没出现过，概率就是 0，连乘后整体概率变 0。解决办法是使用拉普拉斯平滑（Laplace Smoothing）规避该问题。拉普拉斯平滑通过为所有特征计数加 1 来避免零概率。（三种常用变体：MultinomialNB 适合文本计数；GaussianNB 适合连续数值；BernoulliNB 适合 0‑1 二值特征。）
💼 应用场景
文本分类的绝对王者：垃圾邮件/短信过滤、新闻主题分类、情感分析（判断影评是好评还是差评，但需注意否定词结构<如"not good">会挑战条件独立假设，可通过 n-gram 缓解）。
医疗初筛：根据症状推断疾病概率。

## 说明
- 朴素贝叶斯是文本分类的经典基线，尤其适合垃圾短信/邮件过滤
- 该项目重点练习：文本预处理、TF-IDF 特征提取、朴素贝叶斯原理应用





# 项目总结：SMS 垃圾短信分类 — 朴素贝叶斯实战

## 1. 项目背景与业务目标
- **任务**：判断一条短信是**垃圾短信（spam）**还是**正常短信（ham）**（二分类）
- **核心目标**：掌握 **朴素贝叶斯（Naive Bayes）** 在文本分类中的应用，练习完整的 NLP 预处理流程

## 2. 数据概况
| 项 | 内容 |
|---|---|
| 原始数据 | 5,572 条短信 |
| 去重后 | 5,169 条短信 |
| 类别分布 | ham（正常）：87.4%，spam（垃圾）：12.6% |
| 文本特点 | 短信平均长度：正常 70.5 字符，垃圾 137.9 字符 |

- 垃圾短信占比约 12.6%，存在**类别不平衡**
- 垃圾短信通常更长，包含更多促销、奖品相关词汇

## 3. EDA 结论
- **类别分布**：正常短信远多于垃圾短信
- **短信长度**：垃圾短信平均长度约为正常短信的 2 倍
- **高频词对比**：
  - 垃圾短信：free、txt、ur、mobile、stop、claim、reply、prize...
  - 正常短信：im、just、ok、got、know、like...

## 4. 文本清洗与预处理
- **清洗**：转小写、去标点/数字、合并多余空格
- **去重**：移除 403 条重复短信
- **向量化**：使用 TF-IDF（去停用词）将文本转换为 7,108 维稀疏矩阵

## 5. 模型构建
### 朴素贝叶斯变体对比
| 模型 | 准确率 |
|------|--------|
| **MultinomialNB** | **0.9623** |
| BernoulliNB | 0.9613 |

- **MultinomialNB**：适合词频/词权重类特征，是文本分类的标准选择
- **BernoulliNB**：适合"词是否出现"的二值特征

## 6. 模型评估
- **混淆矩阵**：
  - 正常短信：precision=0.96，recall=1.00
  - 垃圾短信：precision=0.99，recall=0.71
- **分类报告**：macro avg F1-score=0.90，weighted avg F1-score=0.96
- **错误分析**：39/1034 条错误，主要是垃圾短信被误判为正常（recall 0.71）

## 7. 实战测试
- 用最佳模型（MultinomialNB）对自定义短信进行分类
- 示例：
  - "Congratulations! You have won a free iPhone..." → spam（94.61%）
  - "Hey, are you free for dinner tonight?" → ham（0.87%）

## 8. 项目收获
- 掌握朴素贝叶斯的贝叶斯定理、条件独立假设
- 学会文本清洗、TF-IDF 向量化的完整流程
- 理解类别不平衡对模型的影响（垃圾短信 recall 较低）
- 实践文本分类的标准评估方法

## 9. 可优化方向
- 尝试 n-gram（如 bigram）捕捉"not good"等否定结构
- 调参：alpha（平滑参数）
- 尝试其他分类器（如逻辑回归、SVM）对比
- 使用 Word Embedding（如 Word2Vec）替代 TF-IDF
