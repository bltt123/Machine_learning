# AdaBoost / GBDT / XGBoost / LightGBM / CatBoost 实战

## 项目简介
使用同一份结构化信用数据，对比 **AdaBoost、GBDT、XGBoost、LightGBM、CatBoost** 五种 Boosting 家族模型，理解 Boosting 思想从早期到现代工程化版本的演进过程。

本项目重点关注：
- 类别不平衡处理
- 树模型对缺失值与异常值的鲁棒性
- Boosting 家族的原理差异
- 传统 GBDT 与工程优化版本的对比

## 算法介绍
### 1. AdaBoost（Adaptive Boosting）
**通俗理解**：像一份会不断修正的“错题本”。
模型每训练一轮，就提高被分错样本的权重，让下一轮更关注这些难样本，最后把多个弱分类器加权组合起来。
**核心特点**：
- 串行训练，后一个模型依赖前一个模型的结果
- 对错分样本不断加权
- 适合干净、噪声较少的数据
**优点**：
- 思路直观，便于理解 Boosting 的基本思想
- 在一些简单问题上效果不错
**缺点**：
- 对噪声和离群点比较敏感
- 异常样本可能被反复强调，导致过拟合

### 2. GBDT（Gradient Boosting Decision Tree）
**通俗理解**：像接力修正误差。前一棵树预测完后，下一棵树专门去拟合前一轮留下的残差或负梯度，逐步逼近真实结果。
**核心特点**：
- 每一轮拟合的是损失函数的负梯度
- 通过学习率控制每棵树的贡献
- 是很多现代 Boosting 模型的理论基础
**优点**：
- 在结构化数据上很强
- 可解释性和效果之间平衡较好
**缺点**：
- 训练速度不如后来的工程优化版本
- 对参数较敏感
- 原生实现不支持 `class_weight`，不平衡问题通常通过 `sample_weight` 或采样策略处理

### 3. XGBoost（eXtreme Gradient Boosting）
**通俗理解**：GBDT 的“正则化与数学”终极进化版，它继承了 GBDT 拟合负梯度的思想，但在损失函数中加入了正则项，并使用二阶导数信息进行更精细的优化。
- 如果说原生 GBDT 是一辆马力强劲但容易失控的赛车，那 XGBoost 就是给这辆车装上了“顶级悬挂系统”和“精密刹车”。它继承了 GBDT 拟合负梯度的接力思想，但通过极其严谨的数学推导，加入了防过拟合的“刹车机制”，并优化了计算速度，成为了工业界的绝对标杆。
**核心原理**：
- 目标函数加入正则项：XGBoost 在损失函数中加入了树的复杂度惩罚项（叶子节点数量和叶子节点权重的 L2 惩罚）。这就像给模型戴上了“紧箍咒”，有效防止过拟合（原生 GBDT 没有内置这种正则）。
- 二阶泰勒展开（二阶导数优化）：原生 GBDT 只用了损失函数的一阶导数（梯度），而 XGBoost 用到了二阶导数（Hessian 矩阵）。这让模型在寻找最优分裂点时，不仅知道“方向”，还知道“步长”，收敛更快、更准。
- 多项工程优化：支持列抽样（借鉴随机森林）、支持自定义损失函数；建树过程中特征维度的分裂计算可并行加速（注意：树本身依然是串行生成的），极大地提升了训练速度。支持列采样、并行计算、缺失值自动处理等工程优化。
**优点**：
- 结构化数据比赛中的经典强模型
- 泛化能力强，性能稳定
**缺点**：
- 参数较多，需要调参
- 模型复杂度高于原生 GBDT
💼 应用场景
Kaggle 霸主：自 2014 年问世以来，几乎包揽了所有结构化数据比赛的冠军。
工业界万金油：金融风控、广告 CTR 预估、医疗疾病预测等几乎所有结构化数据任务的默认首选。

### 4. LightGBM（Light Gradient Boosting Machine）
**通俗理解**：可以把它看成“更快、更省内存”的 GBDT 加强版。它在保持 Boosting 思想的基础上，重点优化了训练速度和内存效率。
- 当数据量达到百万、千万级时，XGBoost 也会觉得吃力。LightGBM 就像是把 XGBoost 换上了“涡轮增压”和“智能导航”。它通过极其聪明的采样和特征打包技术，在几乎不损失精度的前提下，把训练速度提升了数倍，内存占用大幅降低。
**核心原理**：
- 直方图算法（Histogram）：不再像 XGBoost 那样遍历所有可能的分裂点，而是把连续特征离散化成一个个“桶（Bin）”，在桶里找最优分裂点，极大地降低了计算复杂度。减少分裂搜索开销
- GOSS（单边梯度采样）：LightGBM 发现，那些梯度很小的样本（通常是已经被分得很好的简单样本）对训练贡献不大。于是它保留所有大梯度的难样本，随机采样一部分小梯度的简单样本，从而大幅减少数据量。减少无效样本计算
- EFB（互斥特征捆绑）：很多特征（如 One-Hot 编码后的特征）是互斥的（不可能同时为 1）。LightGBM 把这些互斥特征打包成一个特征，大幅降低了特征维度。压缩高维稀疏特征
- Leaf-wise（按叶子生长策略）：XGBoost 是按层生长（Level-wise），而 LightGBM 优先分裂增益最大的叶子。这种贪心策略训练更快，但由于 leaf-wise 生长方式更激进，更容易过拟合，因此更需要重点控制 `num_leaves` 和 `min_data_in_leaf`，`max_depth` 也可以作为辅助约束，但不是最核心的控制项。
**优点**：
- 训练速度快
- 内存占用低
- 适合大规模数据和高维特征
**缺点**：
- 如果约束不够，容易比层级生长树更快地过拟合
💼 应用场景
海量数据首选：当数据量超过几十万甚至上百万，且特征维度极高时，LightGBM 是绝对的王者。
快速迭代场景：需要频繁调参、快速验证想法的算法工程师的最爱。

### 5. CatBoost（Categorical Boosting）
**通俗理解**：这是一个对类别特征非常友好的 Boosting 模型。如果数据里有大量“性别、城市、类别、标签”这类字段，CatBoost 往往能直接发挥优势。
- XGBoost 和 LightGBM 本质上都是处理数字的。遇到“城市”、“性别”这种类别特征时，必须手动做 One-Hot 或 Label Encoding，非常繁琐。CatBoost 就像是一个“懂业务”的专家，它能直接“看懂”类别特征，自动处理，而且还能有效避免数据泄露（Target Leakage）。
**核心原理**：
- 原生类别特征自动编码：CatBoost 内部使用了一种基于统计的方法（Ordered Target Statistics，有序目标统计），自动将类别特征转化为数值，并自动处理缺失值。原生支持类别特征
- Ordered Boosting（有序提升）：为了防止在使用类别特征时发生“目标泄露（Target Leakage）”，CatBoost 在训练时会模拟时间序列的顺序，确保当前样本在计算统计量时，只使用它“之前”的样本信息。减少目标泄漏，降低训练偏差
- 基线效果优秀 & 对称树结构：默认参数通常就能跑出非常好的效果（但复杂数据集依然需要调参控制过拟合）；其内置的对称树结构让推理（预测）速度极快。
**优点**：
- 类别特征处理能力强
- 防止 target leakage 的机制设计得很完整
- 在很多结构化数据上开箱即用
**缺点**：
- 对纯数值数据集来说，优势可能不如 XGBoost / LightGBM 那么突出
- 训练参数也需要一定理解
💼 应用场景
高类别特征数据：如电商数据（海量商品ID、用户ID、类目）、用户行为日志等。
快速 Baseline：当拿到一份包含大量文本类别的新数据，不想花几天时间做特征工程时，直接扔给 CatBoost，往往会有惊喜。

## 五种模型对比

| 模型 | 核心思想 | 优势 | 适合场景 |
|------|----------|------|----------|
| AdaBoost | 迭代提高错分样本权重 | 思路简单、便于理解 | 干净数据、小规模教学案例 |
| GBDT | 拟合负梯度 | 结构化数据强 | 传统风控、推荐、排序 |
| XGBoost | GBDT + 正则化 + 二阶优化 | 稳定、强大、经典 | 竞赛和工业界常用基线 |
| LightGBM | 高效直方图 + leaf-wise 生长 | 快、省内存 | 大数据、高维数据 |
| CatBoost | 原生类别特征 + 有序统计 | 类别特征处理强 | 类别变量很多的任务 |





# 项目总结：Give Me Some Credit — Boosting 家族 5 模型演进实战

## 1. 项目背景与业务目标
- **业务问题**：根据借款人信用特征，预测其未来两年内严重逾期（违约）的概率（二分类）
- **项目目的**：
  - 重点练习 XGBoost、LightGBM、CatBoost 三种现代 Boosting 模型
  - 并纳入 AdaBoost、GBDT 完成 **5 代 Boosting 家族完整演进对比**
  - 理解 Boosting 思想从"样本加权"到"工程化优化"的发展脉络
- **为什么选择 GMSC**：
  - 15 万行训练数据，能体现新模型的速度与工程优势
  - 违约率仅约 6.7%，类别不平衡明显，适合练习不平衡处理
  - 月收入缺失约 20% + 多特征极端离群值，可展示树模型鲁棒性
  - 与之前的逻辑回归、GMSC 逻辑回归项目形成完整学习链条

## 2. 数据概况
| 数据集 | 规模 | 说明 |
|---|---|---|
| cs-training.csv | 150,000 × 12 | 训练集，含标签 SeriousDlqin2yrs |
| cs-test.csv | 101,503 × 11 | 测试集，无标签 |
| sampleEntry.csv | 101,503 × 2 | 官方提交样例 |

- 10 个特征：RevolvingUtilizationOfUnsecuredLines、age、DebtRatio、MonthlyIncome、各类逾期次数、信贷账户数、房产贷款数、家属数
- 标签：0=正常（约 93.3%），1=违约（约 6.7%）→ **严重类别不平衡**
- 缺失值：MonthlyIncome（约 20%）、NumberOfDependents（少量）

## 3. 探索性数据分析（EDA）
- 标签分布严重不平衡，违约客户仅约 1 万人，训练时需重视少数类
- 多个特征极度右偏：DebtRatio（max 32 万+）、RevolvingUtilization、MonthlyIncome（max 300 万+），绝大多数样本集中在极小值附近
- 逾期相关特征（30-59 / 60-89 / 90 天逾期次数）对违约区分的直观效果明显

## 4. 数据清洗（防数据泄漏）
- **统计量只从训练集计算**，再应用到训练/测试集，防止数据泄漏：
  - MonthlyIncome、NumberOfDependents → 训练集中位数填充
  - 5 个极端右偏特征（含 DebtRatio、RevolvingUtilization、三类逾期次数）→ 99 分位 Winsorize 剪裁
  - age → 约束到 18–100
- 树模型本身支持缺失值，但统一清洗后便于公平对比

## 5. 模型构建（Boosting 家族 5 模型）
统一使用 80/20 分层切分 + 5 折分层交叉验证（StratifiedKFold），每个模型均做了**不平衡处理**：
| 模型 | 核心机制 | 不平衡处理 |
|------|----------|-----------|
| AdaBoost | 自适应样本权重提升（stump 弱学习器） | 弱学习器 class_weight="balanced" |
| GBDT | 拟合损失函数负梯度 | 原生不支持 class_weight，靠分层抽样+AUC 评估 |
| XGBoost | 正则化 + 二阶泰勒展开 | scale_pos_weight（负/正样本比） |
| LightGBM | 直方图 + GOSS + EFB + leaf-wise 生长 | class_weight="balanced" |
| CatBoost | 有序目标统计 + 对称树 | auto_class_weights="Balanced" |

## 6. 模型评估与结果
评价指标：验证集 AUC、5 折 CV-AUC、KS、混淆矩阵、分类报告、ROC 曲线，阈值 0.3/0.5 调优。

| 模型 | 验证集 AUC | 5 折 CV-AUC |
|------|-----------|------------|
| XGBoost | 0.8687 | 0.8656 |
| CatBoost | 0.8685 | 0.8647 |
| LightGBM | 0.8678 | 0.8649 |
| GBDT | 0.8653 | 0.8620 |
| AdaBoost | 0.7808 | 0.7851 |

**结论**：
- XGBoost / LightGBM / CatBoost 三家几乎打平（5 折 CV-AUC ≈ 0.865）
- 三者在 AUC 上均**优于 GBDT**，且训练速度快得多
- AdaBoost 明显垫底（对 GMSC 这种含离群值、右偏的"脏数据"特别敏感，高度符合其算法弱点）
- 全部 Boosting 模型显著超越之前逻辑回归基线（0.8266），体现树模型在此类数据上的优势

## 7. 特征重要性
- 各模型 Top 特征高度一致：RevolvingUtilizationOfUnsecuredLines、逾期次数类特征、DebtRatio 最重要
- 与业务常识吻合：借款人的"额度使用率 + 历史逾期"是违约最强信号
- 注意不同库的重要性口径不同（gain/split/PredictionValuesChange），只能看趋势、不能跨库比绝对值

## 8. 预测与提交
- 用最佳模型（XGBoost）对测试集输出违约概率
- 生成 submission.csv：101,503 行，格式与官方样例一致（Id + Probability）

## 9. 项目收获
- 掌握 Boosting 家族从 AdaBoost → GBDT → XGBoost → LightGBM → CatBoost 的演进脉络与核心差异
- 学会四种不平衡处理方式（class_weight / scale_pos_weight / 样本权重 / 自动权重）
- 理解新老 Boosting 模型在"精度 + 速度 + 内存"三维度的工程化进化
- 实践风控场景的完整建模闭环：清洗 → 建模 → CV → 阈值分析 → 提交

## 10. 可优化方向
- 对 XGBoost / LightGBM / CatBoost 做 GridSearchCV 精细调参
- 尝试 SMOTE 过采样对比
- 用 LightGBM/CatBoost 原生类别特征能力（本数据以数值为主，优势有限）
- 概率校准（Platt scaling）提升分数可信度
